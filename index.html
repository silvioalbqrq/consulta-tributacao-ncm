Conferência IBS / CBS por NCMCST × cClassTrib a partir de XML de NF-e/NFC-e ou planilha

Envie os arquivos e confira, item a item, se o CST e o cClassTrib informados correspondem ao NCM na base de classificação tributária do IBS/CBS. Nenhum arquivo sai do seu computador: todo o processamento é feito no navegador.

Base: Portal da Conformidade Fácil (SEFAZ-RS) IT 2025.002 — NCMs com regra —

1Enviar XML ou planilha

XML de NF-e/NFC-e (pode enviar vários de uma vez) ou planilha .xlsx, .xls ou .csv com uma coluna de NCM.

Arraste os arquivos aqui ou clique para selecionar XML · XLSX · XLS · CSV Para muitas notas, selecione todos os XML de uma pasta de uma só vez.

    2Consultar um NCM

    Pesquise a tributação de um NCM sem enviar arquivo. Aceita 4 a 8 dígitos; a busca por prefixo lista os NCMs da base.

    Como o cálculo é feito

    O NCM de cada item é procurado nos anexos da classificação tributária do IBS/CBS.

    Sem vínculo nos anexos, a tributação é integral (CST 000 / cClassTrib 000001).

    Com vínculo, o site compara o par declarado com as possibilidades permitidas e mostra as vedadas quando existirem.

    Quando o NCM tem mais de uma possibilidade, você pode escolher a tributação do item na coluna Correto (ou no detalhe, em “Usar esta tributação”); a escolha vai para a planilha corrigida.

    Privacidade

    Os arquivos são lidos localmente pelo navegador.

    Nada é enviado, gravado ou compartilhado.

    Para atualizar a base: python scripts/atualizar_base.py

    Consulta de apoio, sem vínculo com SEFAZ ou Receita Federal. Antes de usar fiscalmente, confirme a classificação no portal oficial e avalie a condição de uso de cada produto (os anexos podem alcançar apenas parte dos itens de um mesmo NCM).
